# 🌐 EDUNET — Sistema de Comercialização de Serviços de Internet Banda Larga

Sistema web desenvolvido para gerenciamento e comercialização de serviços de internet banda larga, oferecendo uma interface moderna, intuitiva e responsiva para clientes e administradores.

---

## 📌 Sobre o Projeto

O **EDUNET** foi desenvolvido com foco em proporcionar uma experiência simples e eficiente na contratação e gerenciamento de planos de internet banda larga.

O sistema conta com:

- Interface web responsiva
- Comunicação com API em C#
- Integração com banco de dados
- Estrutura organizada e escalável
- Navegação moderna e intuitiva
